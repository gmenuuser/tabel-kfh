Табель КФХ

Приложение для Android: табель, уголь, скот и агрокалькуляторы — то же хозяйство, что и на iPhone и на сайте.

Скачать приложение

Нужен Android 8.0 или новее.

Как установить

  1. Нажмите «Скачать приложение». Файл TabelKFH.apk попадёт в загрузки браузера.
  2. Откройте скачанный файл (шторка уведомлений → загрузка, или папка «Загрузки» / «Файлы»).
  3. Если телефон пишет, что установка из этого источника запрещена, — разрешите её браузеру (ниже написано, где это) и откройте файл ещё раз.
  4. Нажмите «Установить», затем «Открыть». Войдите с тем же логином и паролем, что на сайте.

Как разрешить установку из браузера

Honor и Huawei (Magic UI / EMUI)

Настройки → Безопасность (или «Безопасность и конфиденциальность») → Дополнительные настройки → Установка приложений из внешних источников → выберите браузер (Chrome, Браузер Huawei) → включите «Разрешить установку».

На старых версиях: Настройки → Безопасность и конфиденциальность → Неизвестные источники → включить. Если телефон предупреждает о «небезопасном приложении» или предлагает проверку — нажмите «Всё равно установить» / «Подробнее → Установить».

Samsung

Настройки → Безопасность и конфиденциальность → Установка неизвестных приложений → браузер → «Разрешить из этого источника».

Xiaomi, Redmi

Настройки → Защита конфиденциальности → Особые разрешения → Установка неизвестных приложений → браузер → разрешить.

Другие телефоны (чистый Android)

Настройки → Приложения → Специальный доступ → Установка неизвестных приложений → браузер → «Разрешить из этого источника». Чаще всего телефон сам показывает кнопку «Настройки» в окне запрета — она ведёт туда же.

Обновление

Новая версия ставится тем же способом поверх старой — записи и вход сохраняются. В приложении: Настройки → «О приложении» показывает версию и, когда есть новая, кнопку «Скачать новую версию».

Если при установке новой версии телефон предлагает сначала удалить приложение — не удаляйте: такое бывает только с файлом не с этой страницы. Скачайте файл отсюда ещё раз.
