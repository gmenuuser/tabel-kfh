# Табель КФХ

Приложение для iPhone (iOS 17 и новее), в котором руководитель «КФХ Зубахин» ведёт учёт рабочего времени
сотрудников. Работает без интернета, все данные хранятся только на телефоне.

Что умеет:

- **Главная** — сегодняшний день: у каждого сотрудника большая кнопка «Пришёл» / «Ушёл», время прихода и
  ухода, отработанные часы; отметку можно поправить.
- **Сотрудники** — список работающих и архив; ФИО, должность, фото, дата приёма и увольнения, график,
  норма часов и перерыв.
- **Календарь** — месяц со статусами по дням (Я — явка, В — выходной, Б — больничный, О — отпуск,
  ОТ — отгул, ПР — прогул, К — командировка); отметки задним числом.
- **Табель** — табель за месяц по всему хозяйству или по одному сотруднику; каждая сборка сохраняется
  отдельной версией. Кнопки «Скачать PDF», «Экспорт в Excel», «Распечатать», «Поделиться».
- **Настройки** — название КФХ, руководитель, ответственное лицо, адрес, телефон (печатаются в табеле);
  резервная копия и восстановление из неё.

Прогул сам не ставится никогда: если отметки нет, день в табеле пустой.

## Как собирается приложение

Mac для сборки не нужен: приложение собирает GitHub Actions (файл `.github/workflows/ios.yml`) на каждый
push в ветку `main`. Сборка:

1. создаёт Xcode-проект из `project.yml` (XcodeGen);
2. запускает все автотесты в симуляторе iPhone — проверки расчётов и табеля, а также UI-тест, который
   проходит по всем экранам и снимает их;
3. собирает неподписанный файл `TabelKFH-unsigned.ipa`.

Результаты сборки (артефакты):

| Артефакт | Что внутри |
|---|---|
| `TabelKFH-unsigned-ipa` | `TabelKFH-unsigned.ipa` — файл для установки на iPhone |
| `review-samples` | примеры PDF и Excel табеля и снимки экранов (`Screens/`) |
| `test-results` | подробные результаты тестов |

## Где взять файл для установки

1. Откройте репозиторий на GitHub → вкладка **Actions**.
2. Выберите последнюю сборку с зелёной галочкой (workflow «iOS»).
3. Внизу страницы сборки, в разделе **Artifacts**, скачайте `TabelKFH-unsigned-ipa`.
4. Распакуйте скачанный zip — внутри `TabelKFH-unsigned.ipa`.

Артефакты хранятся на GitHub ограниченное время (по умолчанию 90 дней). Если старой сборки уже нет,
запустите новую: Actions → iOS → **Run workflow**.

## Установка на iPhone с Windows (Sideloadly)

Нужны: компьютер с Windows, кабель USB для iPhone, Apple ID (подойдёт обычный бесплатный).

1. Установите **iTunes с сайта apple.com** (https://www.apple.com/itunes/ → «Download iTunes for Windows»).
   Версия из Microsoft Store не подходит — Sideloadly нужны драйверы и службы полной версии.
2. Установите **Sideloadly** с https://sideloadly.io.
3. Подключите iPhone кабелем, разблокируйте его и нажмите «Доверять этому компьютеру».
4. Запустите Sideloadly, перетащите в окно `TabelKFH-unsigned.ipa`, выберите свой iPhone и введите Apple ID.
   Нажмите **Start**. Sideloadly сам подпишет приложение вашим Apple ID. При первом входе Apple может
   попросить код двухфакторной проверки — он придёт на ваши устройства.
5. На iPhone включите **режим разработчика**: «Настройки → Конфиденциальность и безопасность → Режим
   разработчика» → включить → перезагрузить телефон → подтвердить. Пункт появляется после первой установки
   через Sideloadly.
6. Разрешите приложение: «Настройки → Основные → VPN и управление устройством» → ваш Apple ID в разделе
   «Приложение разработчика» → **Доверять**.
7. Откройте «Табель КФХ» на домашнем экране.

## Каждые 7 дней — переподписать

Приложение, подписанное бесплатным Apple ID, работает **7 дней**. Потом оно перестаёт открываться
(данные при этом не пропадают). Чтобы продлить:

- подключите iPhone к компьютеру и снова установите тот же (или более новый) `TabelKFH-unsigned.ipa`
  через Sideloadly тем же Apple ID — **поверх** установленного приложения.

Установка поверх **сохраняет все данные**: сотрудников, отметки, табели и настройки.

**Если удалить приложение с iPhone, все данные удалятся вместе с ним.** Поэтому регулярно делайте
резервную копию:

- «Настройки» → **«Создать резервную копию»** → сохраните файл в приложение **«Файлы»** (на iPhone или в
  iCloud Drive).
- Восстановить: «Настройки» → «Восстановить из копии» → выберите файл. Перед заменой приложение покажет,
  что в копии, и спросит подтверждение. Повреждённый или чужой файл не будет принят, текущие данные
  останутся как были.

Совет: делайте копию перед каждым переподписанием и в конце каждого месяца.

## Без переподписи каждые 7 дней (по желанию)

С платной учётной записью **Apple Developer Program** (99 $ в год, https://developer.apple.com/programs/)
приложение можно ставить через **TestFlight**: подпись действует 90 дней на сборку, установка без кабеля и
компьютера. Для этого в `project.yml` указывается команда разработчика (`DEVELOPMENT_TEAM`), а сборка
подписывается и загружается в App Store Connect — это потребует отдельной настройки CI с сертификатами.

## Для разработчиков

Нужен Mac с **Xcode 16** и [XcodeGen](https://github.com/yonaskolb/XcodeGen):

```sh
brew install xcodegen
xcodegen generate          # создаёт TabelKFH.xcodeproj из project.yml (проект в git не хранится)
open TabelKFH.xcodeproj
```

Запуск тестов из командной строки:

```sh
xcodebuild test -project TabelKFH.xcodeproj -scheme TabelKFH \
  -destination 'platform=iOS Simulator,name=iPhone 16,OS=latest'
```

Устройство кода:

- `TabelKFH/Domain` — расчёт времени, сборка табеля, PDF, XLSX (свой ZIP), формат резервной копии;
- `TabelKFH/Services` — работа с базой (SwiftData): отметки, сотрудники, табели, копии;
- `TabelKFH/Features` — экраны (SwiftUI), у каждого своя модель представления;
- `TabelKFHTests` — модульные тесты; `TabelKFHUITests` — проход по экранам со снимками.

Запуск с аргументом `-uitest` открывает приложение с пустой базой в памяти и часами, стоящими на
6 ноября 2026, 09:00 (так UI-тест получает одинаковые снимки); `-uitest-dark` дополнительно включает
тёмную тему. Обычный запуск этими аргументами не затронут.

Сторонних библиотек нет — только Apple SDK. Язык интерфейса — русский.
