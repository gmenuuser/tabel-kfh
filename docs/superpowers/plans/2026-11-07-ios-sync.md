# Синхронизация iPhone — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** iPhone входит на `https://kfh.cubely.ru`, ведёт учёт без связи и синхронизирует его с сервером и сайтом; помощникам админ выдаёт логины без почты.

**Architecture:** Сервер (Fastify + PostgreSQL) получает логины помощников и закрытую регистрацию; сайт — экран «Помощники». На iPhone все `context.save()` сервисов идут через `SyncedSave`, который в той же транзакции SwiftData пишет операции в очередь (`SyncOp`) по разнице с «тенью» записи (`SyncShadow`); `SyncEngine` отправляет очередь и применяет pull — как `web/src/lib/sync.ts`. Выкладка — отдельный стек Docker на VDS Cubely за nginx хоста.

**Tech Stack:** Node 24 + TypeScript + Fastify + pg, React 18 + Vite, Swift 5 / SwiftUI / SwiftData (iOS 17), URLSession, Keychain (Security), Network (`NWPathMonitor`), XcodeGen + GitHub Actions macOS-15.

**Spec:** `docs/superpowers/specs/2026-11-07-ios-sync-design.md`

## Global Constraints

- Адрес сервера в приложении: `https://kfh.cubely.ru` (константа, не настройка).
- Роли: `owner`, `manager`, `timesheet`, `coal`, `livestock`, `viewer`; права проверяет сервер (`server/src/entities.ts`).
- Логин помощника: 3–32 символа `[a-z0-9_-]`, без учёта регистра (хранить в нижнем регистре); пароль ≥ 8 символов (`validPassword`).
- Регистрация хозяйств: `REGISTRATION_OPEN` в `.env`, по умолчанию закрыта.
- Деньги — копейки (Int); даты — ISO 8601 UTC с `Z`; «день» — начало дня по часовому поясу хозяйства, ключ `YYYY-MM-DD`.
- Стабильные id: первые 16 байт SHA-256(UTF-8 имени), `b[6] = b[6] & 0x0f | 0x80`, `b[8] = b[8] & 0x3f | 0x80`; имена `hoursMark:<employeeId>:<YYYY-MM-DD>`, `coalSettings`, `coalWorkDay:<YYYY-MM-DD>`, `deliveryLocation:<название>`, `livestockCategory:<вид>:<название>`, **новые** `farmSettings`, `livestockSettings`. UUID в именах — в нижнем регистре (как у сайта).
- Имена полей на сервере = имена свойств моделей iPhone, но **без суффикса `Raw`** (`kindRaw` → `kind`, `speciesRaw` → `species`, `reasonRaw` → `reason`, `statusRaw` → `status`, `vehicleTypeRaw` → `vehicleType`, `workScheduleRaw` → `workSchedule`). Источник истины — то, что пишет сайт (`web/src/pages/*.tsx`).
- Тексты интерфейса — по-русски, в стиле существующих экранов.
- На VDS Cubely ничего не менять до «выкладывай» владельца; конфиги и скрипты Cubely не трогать.
- Одна рабочая копия — один исполнитель (урок fac94a4).
- Каждое изменение iOS проверяется только CI: `git push` → `bash scripts/ci.sh wait`.

## Review Focus

2. Pull приносит запись, у которой на телефоне есть неотправленная правка: локальные поля не затираются, остальные обновляются — тест в Task 7.
3. Два телефона без связи отмечают часы одному человеку за один день: одна запись (стабильный id), а не две — тест в Task 4 (id) и Task 6 (снятая отметка = `hours: null`).
4. Помощник «табель» после понижения/смены роли не держит на телефоне чужие данные: 401 после смены роли → стирание — тесты в Task 1 (сервер отзывает) и Task 8 (телефон стирает).
5. Часовой пояс хозяйства на сервере отличается от телефона: ключи дней и стабильные id считаются по поясу хозяйства, пришедшему из `/me` — тест в Task 8.
