# «Табель КФХ» Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** An offline iPhone app (iOS 17+) in which the head of «КФХ Зубахин» records employees' attendance by hand, builds monthly timesheets, and exports them to PDF and XLSX, with file backups.

**Architecture:** SwiftUI + SwiftData, MVVM. All rules live in pure, framework-light types under `TabelKFH/Domain` (time arithmetic, timesheet building, PDF, ZIP/XLSX, backup codec) and in `@MainActor` services that wrap a `ModelContext`. Views are thin; each feature has one view model. The Xcode project is generated by XcodeGen from `project.yml`; it is never committed.

**Tech Stack:** Swift 6 toolchain in Swift 5 language mode, SwiftUI, SwiftData, UIKit (`UIGraphicsPDFRenderer`, `UIPrintInteractionController`), PDFKit (tests only), CryptoKit, XCTest. No third-party packages. CI: GitHub Actions `macos-15` with Xcode 16, `brew install xcodegen`.

**Spec:** `docs/spec.md` (owner's text). Read it before every task.

## How work is built and verified (no Mac locally)

The developer machine is Windows; nothing Swift can be compiled there. Every task ends with a push to
`main` (or a PR branch) and a green GitHub Actions run of `.github/workflows/ios.yml`:

1. `xcodegen generate`
2. `xcodebuild test -project TabelKFH.xcodeproj -scheme TabelKFH -destination 'platform=iOS Simulator,name=iPhone 16,OS=latest' -resultBundlePath TestResults.xcresult`
3. Unsigned IPA: `xcodebuild archive … CODE_SIGNING_ALLOWED=NO`, then `Payload/TabelKFH.app` zipped to `TabelKFH-unsigned.ipa`, uploaded as an artifact (installed on the iPhone with Sideloadly from Windows).

"Run the test" in a task means: push, wait for the workflow, read the log/xcresult summary. A step's
expected FAIL is seen in CI too (push the failing test commit first, then the implementation). Every
task's last step is "CI green, artifact built".

## Global Constraints

- iOS deployment target 17.0; iPhone only (`TARGETED_DEVICE_FAMILY = 1`); portrait and landscape allowed.
- No third-party dependencies; Apple SDK only.
- All UI text, document text and error messages in Russian; locale `ru_RU`; weeks start on Monday.
- Default farm name «КФХ Зубахин».
- Status codes and Russian names exactly: Я — явка, В — выходной, Б — больничный, О — отпуск, ОТ — отгул, ПР — прогул, К — командировка.
- Worked time = departure − arrival − break; computed on `Date` values, never on strings.
- A missing mark is never turned into ПР automatically.
- No fake buttons or unfinished screens in the final build; every visible control works.
- Colours: primary dark green `#1F5D3A` (dark mode `#4FA36F`), accent orange `#E8892B`, cards `secondarySystemBackground`, background `systemBackground`.
- Tab bar order and titles: Главная, Сотрудники, Календарь, Табель, Настройки.
- PDF title exactly «ТАБЕЛЬ УЧЁТА РАБОЧЕГО ВРЕМЕНИ»; footer lines exactly «Руководитель КФХ: ___________________» and «Ответственное лицо: ___________________».
- Export button titles exactly «Скачать PDF», «Экспорт в Excel», «Распечатать», «Поделиться».

## Review Focus

- Night shift: arrival 22:00, departure 06:00 next day, break 30 → 450 min; the record belongs to the arrival date. (Task 3, Task 4)
- Leaving the app open past midnight: a person who came yesterday and has no departure must still show «Ушёл» on today's Home screen, not «Пришёл» again. (Task 4)
- Hire/dismissal inside the month: cells before hire and after dismissal are blank and not counted; an employee whose employment does not overlap the month is not in the timesheet at all. (Task 7)
- A record with status Я, arrival set and no departure is "незавершён": shown with «?» in the cell, 0 hours in totals, counted as a явка day, and listed in a warning above the timesheet. (Task 3, Task 7)
- A damaged or foreign backup file (edited JSON, wrong schema version, not our format) is rejected with a Russian message before anything is deleted. (Task 11)

### Task 7: Timesheet document and versions

**Produces:**
```swift
enum CellFormat: String, Codable { case codes, codesAndHours }
struct EmployeeSnapshot: Codable, Equatable { let id: UUID; let fullName, position: String; let hireDate: Date; let dismissalDate: Date? }
struct TimesheetCell: Codable, Equatable { let status: DayStatus?; let minutes: Int?; let unfinished: Bool; let employed: Bool
  var text: String /* "" | "Я" | "Я\n8" | "Я?" ; hours shown as decimal with comma, e.g. "7,5" */ }
struct TimesheetTotals: Codable, Equatable { var presentDays = 0, minutes = 0, dayOff = 0, sick = 0, vacation = 0, timeOff = 0, absent = 0, businessTrip = 0 }
struct TimesheetRow: Codable, Equatable { let number: Int; let employee: EmployeeSnapshot; let cells: [TimesheetCell]; let totals: TimesheetTotals }
struct TimesheetDocument: Codable, Equatable { let month, year, daysInMonth, version: Int; let format: CellFormat
  let farmName, managerName, responsiblePerson: String; let createdAt: Date
  let rows: [TimesheetRow]; let farmTotals: TimesheetTotals; let unfinished: [String] /* "Зубахин И. П. — 5 ноября" */ }
enum TimesheetBuilder { static func build(month: Int, year: Int, employees: [EmployeeSnapshot], records: [RecordSnapshot], settings: FarmInfo, format: CellFormat, version: Int, createdAt: Date) -> TimesheetDocument }
struct RecordSnapshot: Codable, Equatable { let employeeId: UUID; let day: Date; let status: DayStatus; let minutes: Int?; let unfinished: Bool }
struct FarmInfo: Codable, Equatable { let farmName, managerName, responsiblePerson, address, phone, extraInfo: String }
@MainActor final class TimesheetService { init(context:)

  func versions(month: Int, year: Int, employee: Employee?) -> [TimesheetSnapshot]   // newest first
  func document(_ s: TimesheetSnapshot) throws -> TimesheetDocument }
```
Rules: rows = employees whose employment overlaps the month (archived included if they worked in it), sorted by fullName; cells outside employment → `employed: false`, blank, not counted; no record → blank; Я with minutes → counts presentDays and minutes (`effectiveMinutes`); unfinished Я → presentDays +1, minutes +0, text «Я?», listed in `unfinished`; farm totals = sum of rows. Snapshot stores JSON of the document and the employee snapshots, so later edits to employees or records never change a saved version.
