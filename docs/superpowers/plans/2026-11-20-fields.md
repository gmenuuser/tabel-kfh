# Поля («Поля») Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Новый раздел «Поля» — справочник полей хозяйства (название, площадь, культура, заметка) на сайте и на Android, из которого агро-калькуляторы берут площадь.

**Architecture:** Новая сущность синхронизации `field` (модуль `fields`) — обычная запись `records`, без новых HTTP-маршрутов. Права по образцу агро: владелец, управляющий, просмотр — чтение; владелец, управляющий и телефон-«приложение» — запись. Сайт получает страницу `#fields`, Android — экраны `fields`; в агро-калькуляторах появляется выбор поля, который подставляет площадь текстом.

**Tech Stack:** Fastify 5 + Postgres (`server/`), React + Vite (`web/`), Kotlin + Compose + Room (`android/`), тесты — `node --test` и JUnit; Android проверяется только CI.

**Spec:** `docs/superpowers/specs/2026-11-20-fields-design.md`

## Global Constraints

- Площадь — **целое число м²** (`areaSqM`, Long/Number), больше нуля. На экран — «12,5 га», до 4 знаков, запятая.
- Название — 1..60 символов; культура — до 60; заметка — до 200; культура и заметка необязательны.
- Запись — только через синхронизацию (`engine.save` на сайте, `RecordWriter.save` на телефоне). Новых маршрутов сервера нет.
- iPhone (`TabelKFH/`) и локальная копия телефона (`LocalBackup`/`BackupCodec`, схема 5) в этой задаче не меняются.
- Поля не входят в «Очистку периода» и в отчёты.
- Один коммит на задачу. Тексты — по-русски, как в существующих экранах.
- «Просмотр» читает поля, но не меняет.

## Review Focus

1. Площадь, введённая как «12,5», «12.5», «0,0001» и «0» — первые три дают м², «0» и мусор отклоняются с понятным текстом (не сохраняются как 0).
2. Название из одних пробелов или длиннее 60 — отклоняется на клиенте и на сервере.
3. Удаление поля, на которое ссылался сохранённый агро-расчёт, — текст расчёта цел (в расчёт не попадает никакой `fieldId`; проверяется grep-ом в Task 4 и ревьюером).
4. Помощник «только табель» не видит полей на сайте (`#fields` → главная) и получает отказ сервера, если пришлёт запись.
5. Старая сборка телефона, получив записи `field`, не падает: строки лежат в общей таблице и не показываются.

```ts
import { test } from 'node:test';
import assert from 'node:assert/strict';
import { areaHa, culturesOf, fieldErrors, fieldLabel, parseAreaSqM, sortFields } from '../src/lib/fields.ts';

test('площадь: запятая, точка, четыре знака, ноль', () => {
  assert.equal(parseAreaSqM('12,5'), 125000);
  assert.equal(parseAreaSqM('12.5'), 125000);
  assert.equal(parseAreaSqM('0,0001'), 1);
  assert.equal(parseAreaSqM('0'), null);
  assert.equal(parseAreaSqM(''), null);
  assert.equal(parseAreaSqM('abc'), null);
  assert.equal(parseAreaSqM('1,23456'), null, 'пять знаков — больше, чем нужно');

test('показ площади — до четырёх знаков без хвостовых нулей', () => {

  assert.equal(areaHa(12345), '1,2345');

test('проверки: пустое имя, пробельное имя, длинное имя, площадь', () => {

  assert.deepEqual(fieldErrors({ name: '   ', areaSqM: 100 }), ['Название поля — от 1 до 60 символов']);
  assert.deepEqual(fieldErrors({ name: 'я'.repeat(61), areaSqM: 100 }), ['Название поля — от 1 до 60 символов']);
  assert.deepEqual(fieldErrors({ name: 'Поле 1', areaSqM: 12.5 }), ['Площадь — целое число м² больше нуля']);
  assert.deepEqual(fieldErrors({ name: 'Поле 1', areaSqM: 100, culture: 'к'.repeat(61) }), ['Культура — до 60 символов']);
  assert.deepEqual(fieldErrors({ name: 'Поле 1', areaSqM: 100 }), []);
});

test('сортировка по названию по-русски и список культур', () => {
  const rows = [
    { id: '1', data: { name: 'Яблоневый', areaSqM: 100, culture: 'Пшеница' } },
    { id: '2', data: { name: 'Ближний', areaSqM: 100, culture: '' } },
    { id: '3', data: { name: 'Верхний', areaSqM: 100, culture: 'Овёс' } },
```
